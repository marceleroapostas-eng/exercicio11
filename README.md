\# Exercício 11 - Múltiplo de 2



\## Descrição



Este programa solicita um número inteiro ao usuário e verifica se ele é múltiplo de 2.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém um número inteiro informado pelo usuário.



\## Saída



O programa informa se o número é ou não múltiplo de 2.
